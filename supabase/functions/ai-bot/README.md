# MITAL AI-помощник в Telegram

Бот отвечает на вопросы по работе (текстом или голосом, на русском или узбекском) по данным MitalCRM:
остаток и долг клиента, заказы и оплаты за период, сколько сделал агент, сравнение агентов, должники,
кого дожимать сегодня, «спящие» клиенты, топ товаров, остатки складов, фото договора.

Как устроен: Telegram → Supabase Edge Function `ai-bot` → Gemini. Gemini только понимает вопрос и пишет ответ.
Все цифры считает код функции из репозитория `mitalcrm-data`, то есть из тех же файлов, что использует CRM:
автозагрузка LINKO, архив по дням, рассрочка, состояние CRM. Поэтому придумать цифру бот не может.

## Настройка (один раз, примерно 15 минут)

1. **Новый бот.** В Telegram откройте @BotFather → `/newbot` → назовите, например, «MITAL AI». Скопируйте токен.
   Нужен именно новый бот: у бота для агентов уже есть свой webhook, а у одного бота webhook может быть только один.
2. **GitHub-токен только на чтение.** github.com → Settings → Developer settings → Fine-grained tokens → Generate:
   Repository access: только `mitalcrm-data`; Permissions → Contents: **Read-only**. Скопируйте токен.
3. **Ключ Gemini.** Подойдёт тот же, что в CRM (Аналитика → ИИ-ассистент), или новый на aistudio.google.com.
4. **Функция в Supabase.** supabase.com → проект MitalCRM → Edge Functions → Deploy a new function → Via Editor.
   Имя: `ai-bot`. Вставьте весь код из `index.ts` → Deploy.
   Потом в настройках функции выключите **Verify JWT** (Telegram не умеет его присылать).
5. **Секреты.** Edge Functions → Secrets → добавьте:
   - `TG_TOKEN`: токен из шага 1
   - `TG_SECRET`: придумайте длинный пароль (латиница и цифры, например `mital2026ai_x7k9q`)
   - `GEMINI_KEY`: ключ из шага 3
   - `GH_TOKEN`: токен из шага 2
   - `ALLOWED_USERS`: пока оставьте пустым (см. шаг 7)
6. **Подключите webhook.** Откройте в браузере:
   `https://oxchgcfyzszemqlvdjjr.supabase.co/functions/v1/ai-bot?setup=ВАШ_TG_SECRET`
   Должно появиться `"ok": true`.
7. **Доступ.** Напишите боту что угодно. Он ответит «Нет доступа. Ваш Telegram ID: 123456789».
   Вставьте этот номер в секрет `ALLOWED_USERS`. Готово: напишите `/help`.

Через Supabase CLI вместо шага 4: `supabase functions deploy ai-bot --no-verify-jwt`.

## Команды (мгновенно и без ИИ, лимит Gemini не тратят)
- `/today`: кого дожимать сегодня (`/today Адхамжон` покажет одного агента)
- `/dolg`: должники (`/dolg Адхамжон`)
- `/agents`: итоги агентов за текущий плановый период
- `/k Фозилхон`: карточка клиента
- `/sleep`: кто давно не брал товар
- `/sklad Liman ATF`: остатки на складах
- `/data`: когда обновлялись данные
- `/fresh`: перечитать данные сразу (обычно бот берёт новые данные каждые 2 минуты)
- `/new`: начать разговор заново (бот помнит последние ~6 вопросов в течение часа)
- `/help`: примеры вопросов

## Экономия лимитов
- Простой вопрос («сколько», «какой остаток», «покажи») — 1 запрос к Gemini: ИИ только понимает вопрос, а ответ бот собирает сам по шаблону.
- Вопрос с анализом или советом («кто работает лучше и почему», «что делать с этим клиентом») — 2–3 запроса.
- Тот же вопрос повторно в течение 5 минут — 0 запросов, ответ берётся из памяти.
- Голосовое тратит столько же запросов, сколько и текст.
- Модель по умолчанию `gemini-3.1-flash-lite`, у неё самые большие бесплатные лимиты. Сменить модель можно секретом `GEMINI_MODEL`.

## Что важно знать
- Данные такие же свежие, как автозагрузка LINKO (раз в 5 минут). История заказов и оплат есть с первого дня архива (сейчас с 16.10.2026).
- Оплаты по транзакциям LINKO — это наличные. Переводы на карту или счёт видны в баланс-файле, бот показывает их отдельно.
- Отменённые заказы (статус 4 в LINKO) в продажи не входят.
- Скан договора бот пришлёт, только если он прикреплён в CRM → Деньги → Рассрочка и договоры.
- На бесплатном ключе Gemini Google может использовать запросы для улучшения своих моделей. Если это важно, включите платный тариф в AI Studio: он стоит копейки при одном пользователе. Модель меняется секретом `GEMINI_MODEL`.
