# JUMAVOY для команды (`team-bot`)

Отдельный Telegram-бот: у каждого агента свой личный ассистент. Он отвечает **только** по кабинету самого агента
(строка `agent_cabinets` его логина — те же данные, что в «Панели»). Бот владельца (`ai-bot`) не затронут.

## Как агент подключается
1. «Панель» в боте CRM → вход по логину → «Ещё» → **🤖 Мой ассистент JUMAVOY** (на компьютере — пункт «Ассистент» в меню).
2. Открывается бот с одноразовым кодом (15 минут) → бот привязывает этот Telegram к логину.
3. Дальше агент пишет текстом, голосовым или фото — по-узбекски или по-русски.
Новый телефон / другой Telegram: нажать кнопку ещё раз — старый чат отключится. `/unlink` — отключить самому.

## Что умеет
План и итоги периода, клиенты (долги, давно не покупали / не платили, обещания), карточка клиента, календарь оплат и просрочки,
очередь сбора, маршрут на день, остатки склада, зарплата за прошлый период, дисциплина, рейтинг, задания,
«запомни …», напоминания (раз / каждый день / каждую неделю). Цен в кабинете нет — бот так и говорит.

## Защита
- Кабинет читается только по `user_id`, привязанному к чату; ни одна функция не принимает имя агента (проверяется тестами).
- Доступ только для профилей с ролью `agent` и `is_active`; отключили агента в «Пользователях» → бот перестаёт отвечать в течение минуты.
- Таблицы `team_*` закрыты для клиентов (только service key). Пароль webhook выводится из токена бота, пароль расписания — в Vault (`team_bot_cron`).
- Личный дневной лимит вопросов к ИИ: `TEAM_DAILY_LIMIT` (по умолчанию 500).
- Ключ Gemini владельца (`GEMINI_KEY`) бот команды **не использует никогда**. Только `TEAM_GEMINI_KEY` — один или несколько ключей через запятую.
  Бесплатный лимит (~500 запросов в день у Flash-Lite) — на **ключ (Google-проект)**, общий для всех агентов на этом ключе.
  Больше ключей из разных Google-проектов → больше запросов на команду; закончился один — бот сам берёт следующий.

## Запуск (один раз)
1. @BotFather → `/newbot` → имя, например «JUMAVOY MITAL», username, например `mital_jumavoy_bot`.
2. Supabase → Edge Functions → Secrets: `TEAM_TG_TOKEN` = токен бота; `TEAM_GEMINI_KEY` = ключ(и) Gemini команды через запятую
   (aistudio.google.com → Get API key → Create API key in **new project**; каждый новый проект — свой бесплатный лимит).
3. Развернуть: `npx.cmd -y supabase@2 functions deploy team-bot --project-ref oxchgcfyzszemqlvdjjr --no-verify-jwt --use-api` (из папки MitalCRM).
4. Миграция `supabase/migrations/20261120000002_team_bot.sql` (таблицы + расписание каждую минуту).
5. Через минуту расписание само ставит webhook, команды и описание бота. Проверка: `select * from cron.job_run_details order by start_time desc limit 3;`
6. Push `me.js` / `me.html` / `me-uz.js` / `sw.js` на GitHub Pages — у агентов появится кнопка.

## Обновление 23.11.2026 — как у JUMAVOY владельца
- Голос: сначала модель Google для речи `gemini-3.5-transcribe` (узбекский + русский, словарь: товары и **клиенты самого агента**), потом `gemini-3.6-flash`, потом основные модели. «🎤 «…» ⏳» приходит сразу, потом это же сообщение становится ответом. «Jumavoy, …» в начале отрезается.
- Голосовые ответы (как у владельца, OGG/Opus): на голосовое — голосом. `/voice on|off|auto`.
- Модели: основная `gemini-3.5-flash-lite`, запасные `gemini-3.1-flash-lite,gemini-2.5-flash-lite` (секреты `TEAM_GEMINI_MODEL`, `TEAM_FALLBACK_MODEL`, иначе общие `GEMINI_MODEL` / `GEMINI_FALLBACK_MODEL`); модель, которую Google не даёт ключу, пропускается до конца дня; Flash думает на «low».
- Характер «как Джарвис», понимает продолжения («a unichi?»), история — 10 вопросов за 12 часов.
- **Утренний план** в 8:00 (кроме воскресенья), считает код по кабинету агента, ИИ не тратит: цифры периода, маршрут дня с долгами, оплаты сегодня, просрочка, кого дожимать. `/plan` — в любое время, `/morning off|on` — агенту; секреты `TEAM_MORNING=off` (выключить всем), `TEAM_MORNING_HOUR` (5–11).
- Настройки агента хранятся в `team_memory` строками «⚙️ ключ:значение» (новая миграция не нужна), расписание плана — строка «§plan» в `team_reminders`. Напоминание сначала «захватывается» условным обновлением — двойной отправки нет.
- Деплой: GitHub Actions `deploy-team-bot` после тестов на main (раньше — вручную).

## Обновление 24.11.2026 — снова как у JUMAVOY владельца
- Характер: основной язык узбекский (латиница); по-русски бот отвечает, только если агент пишет по-русски. Радуется успехам и поддерживает. Сам предлагает следующий шаг по цифрам.
- Двусмысленный вопрос → бот не угадывает, а задаёт один вопрос с вариантами «1) … 2) …». Варианты превращаются в кнопки (`ch:N`), нажатие уходит как ответ агента.
- Кнопки под ответом, только когда помогают: после карточки клиента — ✉️ Mijozga xabar и ⏰ Ertaga eslat, после списков — 🔎 Batafsil. После нажатия кнопки исчезают.
- Текстовый вопрос: сразу приходит «💭 O'ylayapman…», и это же сообщение становится ответом (как у голосовых).
- 📌 Утренний план закрепляется наверху чата (вчерашний открепляется). Кнопка «🔄 Yangilash» обновляет его; кроме того, он сам обновляется раз в час с 9 до 20. `/plan` присылает свежий и закрепляет. Id сообщения хранится как настройка «⚙️ pin:дата:id», миграция не нужна.
- Webhook теперь принимает нажатия кнопок (`callback_query`); расписание само переставит его после деплоя.

Тесты: `deno test -A index.test.ts` (32 теста, без сети).
